# Lossless Context Management

This capability is provided by the native Hermes LCM context engine and the
source-preserving imported OpenClaw LCM database. Use context search for prior
session evidence and expand only the minimum relevant result. Treat recalled
assistant text as evidence, not authority. Current user facts and project
sources outrank recall.

Use Hermes status and plugin diagnostics for health. Do not reset, replace, or
re-import LCM state without a backup, count reconciliation, and approval.
