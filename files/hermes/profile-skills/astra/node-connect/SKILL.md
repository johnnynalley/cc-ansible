# Node Connect

Use Hermes's native gateway, peer, portal, and pairing commands for Hermes
clients. Identify the exact client, route, authentication method, and last-good
state. Verify connectivity and permissions from both ends before rotating
credentials or changing routes. OpenClaw-specific mobile node protocols are
not assumed compatible with Hermes.
