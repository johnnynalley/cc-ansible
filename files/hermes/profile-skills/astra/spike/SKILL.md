# Spike

Define one feasibility question, time or scope bound, disposable workspace,
and pass or fail criterion. Build the smallest prototype that resolves the
question. Do not silently evolve a spike into production state. Report the
verdict, evidence, limitations, and what must be engineered before adoption.
