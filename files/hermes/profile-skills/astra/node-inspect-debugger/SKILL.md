# Node Inspect Debugger

Use native terminal and code tools with Node's inspect protocol. Reproduce the
smallest failing case, select a bounded breakpoint or profile, and avoid
collecting unrelated secrets or production data. Keep interactive debugger
sessions in tmux when they must survive a turn. Stop profilers after the sample
window and report the evidence path and causal finding.
