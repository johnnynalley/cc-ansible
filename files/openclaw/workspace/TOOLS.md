# Tool Boundary

Use only tools granted by the effective runtime policy. The production service
has no sudo, Docker socket or group, human-home, controller credential, or
authoritative repository access. Use reviewed aggregate reports, fixed-schema
brokers, and operator/Codex handoff for privileged work.

Check optional paths without failing, inspect structured data before querying
it, and bound shell or network probes. Never print secrets or move credentials
into prompts, logs, plans, files, or chat.
